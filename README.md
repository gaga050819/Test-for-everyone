# SecureExam — гілка без ШІ

У цій гілці вимкнені запити до Gemini, генерація тестів і оцінювання відповідей через ШІ. API-ключ не потрібен і не читається застосунком. Тести можна створювати вручну або імпортувати з тексту через локальний парсер; короткі відповіді перевіряються за заданими варіантами.

## Локальний запуск

Установіть Node.js, потім у PowerShell виконайте:

```powershell
cd server
npm ci
npm start
```

Відкрийте `http://localhost:3500`. За потреби створіть `server/.env` на основі `server/.env.example`. Файл `.env` ігнорується Git — не додавайте до репозиторію паролі чи інші секрети.

## Про GitHub Pages

Це повний застосунок на Express із API, WebSocket і серверним сховищем. GitHub Pages може віддати статичні файли, але не запускає цей сервер, тому повний тестовий застосунок там не запрацює. Для робочого публічного сервісу потрібен хостинг із Node.js, WebSocket і постійним сховищем.
