# SecureExam — окрема гілка без налаштованого ШІ

Ця гілка містить вихідний код SecureExam без `.env` та без Gemini API-ключа. Для звичайного запуску тестів ключ не потрібен; генерація й оцінювання через Gemini без локально налаштованого ключа недоступні.

## Локальний запуск

Установіть Node.js, потім у PowerShell виконайте:

```powershell
cd server
npm ci
npm start
```

Відкрийте `http://localhost:3500`. За потреби створіть `server/.env` на основі `server/.env.example`. Файл `.env` ігнорується Git — не додавайте до репозиторію ключі або паролі.

## Про GitHub Pages

Це повний застосунок на Express із API, WebSocket і серверним сховищем. GitHub Pages може віддати статичні файли, але не запускає цей сервер, тому повний тестовий застосунок там не запрацює. Для робочого публічного сервісу потрібен хостинг із Node.js, WebSocket і постійним сховищем.
