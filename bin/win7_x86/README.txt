=====================================================================
       SecureExam - Портативний набір для Windows 7 (32-біт / x86)
=====================================================================

Ця папка містить повністю ізольовані 32-бітні компоненти:

1. node/ - Портативний Node.js v14.21.3 (32-bit ia32).
   Не потребує встановлення у Windows. Працює одразу.

2. ngrok.exe - 32-бітний клієнт тунелювання ngrok (windows-386).

3. START.bat - Лаунчер запуску.
   Також у кореневій папці створено прямий ярлик:
   "START_WIN7_32BIT.bat"

Основні файли для Windows 10/11 не змінені та знаходяться у корені:
- START_WIN10.bat (або start_win10.ps1)
- ngrok.exe (64-бітний для Windows 10/11)
=====================================================================
